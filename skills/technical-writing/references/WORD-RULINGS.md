# Word Rulings

The Economist's style guide is, at heart, an alphabetical list of rulings on individual words. These are the ones that go wrong most often, in US spelling, plus a short set of rulings specific to technical writing.

Flag a word only when the text uses it in the disputed sense. A correct use of *decimate* is not an error.

## General

| Word | Ruling |
|---|---|
| address (verb) | Vague when applied to a problem. Tackle, fix, or answer |
| aggravate | To make worse. Not to annoy |
| alibi | Proof of being elsewhere, not any excuse |
| alternative | One of two. With more than two, use option or choice |
| anticipate | To act in expectation of, not simply to expect |
| beg the question | To assume what is to be proved, not to raise the question |
| community | Overused. "The developer community" — name who you mean |
| compare | Compare **with** when noting differences. Compare **to** when likening |
| comprise | The whole comprises the parts. Never "comprised of" |
| crisis | A decisive turning point, not any difficulty |
| decimate | To kill one in ten. Do not use it loosely for destroy |
| dilemma | A choice between two unwelcome options, not any problem |
| disinterested | Impartial. *Uninterested* means bored |
| enormity | Great wickedness, not great size |
| epicenter | The point on the surface above an earthquake's focus. Not "the very center" |
| famously | If it is famous you need not say so. If it is not, the word is false |
| flaunt | To display ostentatiously. To break a rule is to **flout** it |
| fortuitous | By chance, not fortunate |
| fulsome | Excessive and insincere. Not abundant |
| hopefully | Not a sentence adverb. Say who hopes |
| iconic | Exhausted. Say why the thing matters |
| imply / infer | Speakers imply. Listeners infer |
| individual (noun) | Prefer person |
| key (adjective) | Overused. Important, main, chief — or cut it |
| less / fewer | Less for quantity, fewer for number: less memory, fewer allocations |
| literally | Not an intensifier. "Literally exploded" means it exploded |
| major | Overused. Big, main — or cut it |
| masterful | Domineering. A skillful performance is **masterly** |
| massive | Reserve for physical mass. Otherwise: large, and say how large |
| may / might | *Might* for hypotheticals and past possibility. *May* for permission and present possibility |
| militate / mitigate | Circumstances **militate** against something. You **mitigate** (soften) an effect |
| ongoing | Continuing — or just cut it |
| practicable | Capable of being done. *Practical* means useful or sensible |
| prevaricate | To speak evasively. To delay is to **procrastinate** |
| protagonist | The chief actor. There is only one |
| refute | To disprove. Someone who merely disagrees **denies** or **rejects** |
| situation | Usually redundant. "A crisis situation" is a crisis |
| transpire | To become known, not to happen |
| unique | Absolute. Nothing is very unique or quite unique |
| viable | Capable of independent life. Overused for feasible |
| while / whilst | *While*. Never *whilst* |

## Technical writing

| Word | Ruling |
|---|---|
| allow / enable / let | Software **lets** a user do something. Reserve *enable* for turning a flag on |
| architect (verb) | Not a verb. Design |
| assure / ensure / insure | Assure a person. Ensure an outcome. Insure a risk |
| can / may / must / should | In a spec these are load-bearing. **Must** is a requirement, **should** a recommendation, **may** an option. Never use them loosely as synonyms, and never swap one for another in an edit |
| deprecated / removed / disabled | Three different states. Deprecated still works |
| e.g. / i.e. | *e.g.* is "for example", *i.e.* is "that is". In machine-read and documentation text (Tiers 1-2), write the English |
| execute | For programs and legal documents. People **run** a command |
| leverage | Use |
| once | Ambiguous between "as soon as" and "one time". Write **after** or **when** |
| performant | Not a word in plain use. Say fast, and give the number |
| please | Not in an error message or a procedure. It adds a word and no information |
| robust / scalable / seamless | Unmeasurable claims. Give the limit, the throughput, or the failure mode |
| simply / just / easy / obviously | Delete every one. If it were easy, the reader would not be here. These words only tell a stuck reader they are stupid |
| since / as | Ambiguous between time and cause. Write **because** when you mean cause |
| support (verb) | Vague. Say what the thing actually does with the input |
| utilize | Use |
| valid / invalid | Say what makes it invalid. "Invalid input" is not an error message |
| we / you / the system | Pick one voice per document. In procedures, address the reader: "Run the migration", not "the user should run the migration" |
